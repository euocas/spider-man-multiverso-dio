# 🕷️ Spider-Man Multiverso

Projeto de desenvolvimento web inspirado no universo do **Spider-Man**, desenvolvido durante estudos de Front-End na **DIO**.

A proposta foi criar uma experiência visual imersiva, trabalhando composição, navegação, hierarquia de informações, efeitos visuais e responsividade.

## 📌 Sobre o projeto

O projeto apresenta uma interface temática baseada no conceito do multiverso do Spider-Man, explorando diferentes personagens e elementos visuais do universo.

Além da implementação proposta durante o curso, foram realizados ajustes e personalizações na interface.

## 🚀 Tecnologias

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## 🎨 Conceitos trabalhados

* Desenvolvimento de interfaces web
* Layout responsivo
* Estruturação semântica com HTML
* Estilização e composição visual com CSS
* Interações com JavaScript
* Navegação entre páginas
* Organização de arquivos e componentes
* Versionamento com Git

## 📱 Responsividade

A interface foi desenvolvida considerando diferentes tamanhos de tela, buscando manter uma boa experiência tanto em dispositivos desktop quanto mobile.

## 📚 Desenvolvimento

Projeto realizado como parte de uma formação em **Front-End pela DIO**, com foco na prática de desenvolvimento de interfaces e construção de experiências web.
